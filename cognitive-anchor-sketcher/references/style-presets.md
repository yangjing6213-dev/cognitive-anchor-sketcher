# 画风预设

## 选择

- `minimal-line`（默认）：读取 `style-dna.md`，不改变现有小黑行为。
- `emotion-doodle`：黑色主导的情绪涂鸦漫画；自然语言别名为“情绪涂鸦漫画”“情绪涂鸦”或“emotion-doodle”。

未指定画风时使用 `minimal-line`。画风只控制渲染语言，不替换 IP 档案。

## emotion-doodle

- 16:9 横版、纯白背景、大留白、主体约 40%-60%。
- 粗而略抖动的黑色手绘轮廓；允许少量灰色速写线、情绪线、速写圈、爆发线、动作线。
- 黑色负责角色、轮廓、主要动作和核心文字。
- 黄色、橙色、蓝色只作少量动作/情绪/反馈点缀；洋红不作为主色。
- 允许夸张表情和动作，但不得变成海报、表情包合集或儿童卡通。
- 禁止渐变、3D 高光、阴影渲染、复杂背景、密集文字、正式流程图、左上角类型标题。

若 IP 自带身份色，只有在用户确认后才保留为次级识别色，不能覆盖黑色主导规则。
